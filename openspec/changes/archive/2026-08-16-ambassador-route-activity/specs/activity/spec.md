# activity delta（ambassador-route-activity）

## ADDED Requirements

### Requirement: 活动管理
admin 端 SHALL 提供活动 CRUD：所属地图（城市）单选（必填、创建后不可变）、活动图片最少 1 张、活动标题（必填）、活动标签（多个文本）、适合周期多选（经期/卵泡期/排卵期/黄体期）、活动级别单选（L1/L2/L3）、活动简介、编辑说、集合地、解散地、交通、签证（均文本）、路线子条目列表（每条为标题+内容，按添加顺序保存与展示）、活动详情说明（富文本，存 HTML）、上线/下线状态。删除为物理删除。

#### Scenario: 创建活动
- **GIVEN** 存在上架城市
- **WHEN** 提交完整活动（2 张图、2 条标签、周期多选、级别 L2、2 条路线子条目、富文本详情、上线）
- **THEN** 返回 200，详情字段齐全，路线子条目按提交顺序返回，详情 HTML 原样保存

#### Scenario: 缺少必填项被拒绝
- **GIVEN** 已登录 admin
- **WHEN** 提交缺标题或图片为空或城市不存在的活动
- **THEN** 返回 400 及中文业务错误

#### Scenario: 活动上下线切换
- **GIVEN** 一个上线活动
- **WHEN** 将其下线
- **THEN** 返回 200，详情 online=false

### Requirement: App 端活动查询
app 端 SHALL 提供只读查询：按城市查活动列表（含图片、标题、标签、级别、周期）与活动详情（含全部字段与富文本 HTML）。仅当城市上架**且**活动上线时可见；不可见活动详情返回 404。

#### Scenario: 查询上架城市的活动
- **GIVEN** 上架城市下有上线活动
- **WHEN** app 端按该城市查活动列表
- **THEN** 返回 200，含标题、图片、级别、周期字段

#### Scenario: 下线活动不可见
- **GIVEN** 一个下线活动
- **WHEN** app 端查该城市活动列表及该活动详情
- **THEN** 列表不含该活动；详情返回 404

#### Scenario: 活动详情返回富文本
- **GIVEN** 一个可见活动，详情说明为含图片标签的 HTML
- **WHEN** app 端查该活动详情
- **THEN** 返回 200，detailHtml 与后台保存内容一致

### Requirement: web 端活动管理页面
web 端 SHALL 提供「活动管理」后台页面：DataTable 列表（图片/标题/所属城市/级别/状态/操作）+ 表单（含标签、周期多选、级别单选、路线子条目增删、富文本编辑器仅用于活动详情说明）+ 上下线开关 + 删除确认弹窗。

#### Scenario: 活动列表与上下线
- **GIVEN** 已登录后台且存在活动
- **WHEN** 进入活动管理页并切换某活动状态开关
- **THEN** 列表展示图片、标题、所属城市、级别，切换后状态即时更新并有成功提示

#### Scenario: 活动表单富文本编辑
- **GIVEN** 活动编辑表单已打开
- **WHEN** 在活动详情说明的富文本编辑器中输入图文内容并保存
- **THEN** 保存成功，重新打开表单富文本内容回显
