# Proposal: 推荐清单城市-商户联动与下架联动

## 问题
当前推荐清单创建/编辑时，城市与商户无联动校验；商户后期下架不会级联下架相关推荐清单，可能导致 app 端展示已失效内容。

## 目标
- 推荐清单创建/编辑时，先选所属城市，再仅允许选择该城市且未下架的商户。
- 商户下架时，级联下架相关推荐清单；恢复商户后不自动恢复，需人工复核。

## 范围
- web 后台：推荐清单表单城市-商户级联、状态维护。
- admin 后端：清单创建/编辑校验、商户下架级联、清单状态枚举。
- app 端：仅返回 `ONLINE` 推荐清单。

## 依赖

- merchant living spec（消费商户下架状态）
