## MODIFIED Requirements

### Requirement: 文章管理
admin 端 SHALL 提供文章 CRUD：文章图片 1 张（必填）、文章标题（必填，详情页展示）、封面标题（可空，列表/封面展示）、文章副标题（可空）、文章引言（可空，详情页导语）、文章标签（可空，字符串数组，表单内输入即建、无独立标签表）、文章内容（富文本存 HTML，img src 存 objectKey、读时替换签名 URL）、文章权重（排序号）、关联栏目多选（一篇文章可属多个栏目，栏目必须存在）、上线/下线状态。删除为物理删除。存量文章的封面标题与引言为空、标签为空数组，不做数据迁移。

#### Scenario: 创建文章
- **GIVEN** 存在两个栏目
- **WHEN** 提交关联这两个栏目、含富文本内容的完整文章
- **THEN** 返回 200，详情字段齐全，关联栏目为两个，富文本 HTML 保存成功

#### Scenario: 创建带封面标题、引言与标签的文章
- **GIVEN** 已登录 admin
- **WHEN** 提交同时含文章标题、封面标题、引言与两个标签的文章
- **THEN** 返回 200，详情中封面标题、引言、标签数组按提交值原样返回，且与文章标题、副标题互不覆盖

#### Scenario: 封面标题、引言、标签均可省略
- **GIVEN** 已登录 admin
- **WHEN** 提交不含封面标题、引言、标签字段的文章
- **THEN** 返回 200，详情中封面标题与引言为 null、标签为空数组

#### Scenario: 缺少必填项被拒绝
- **GIVEN** 已登录 admin
- **WHEN** 提交缺标题或缺图片或关联了不存在栏目的文章
- **THEN** 返回 400 及中文业务错误

#### Scenario: 文章上下线切换
- **GIVEN** 一个上线文章
- **WHEN** 将其下线
- **THEN** 返回 200，详情 online=false

### Requirement: App 端文章查询
app 端 SHALL 提供只读查询：栏目列表（按权重升序，含名称与 icon）、按栏目查文章列表（按文章权重升序，含图片、封面标题、副标题、标签）、文章详情（含文章标题、副标题、引言、标签、富文本 HTML，img src 为签名 URL）。文章列表返回的封面标题在文章未设置封面标题时 SHALL 回落为文章标题。文章仅当上线**且**至少关联一个仍存在的栏目时可见；不可见文章详情返回 404。

#### Scenario: 查询栏目与文章列表
- **GIVEN** 存在两个栏目（权重 2、1），权重小的栏目下有两篇上线文章（权重 3、1）
- **WHEN** app 端查栏目列表、再按该栏目查文章列表
- **THEN** 栏目按权重升序返回；文章按权重升序返回，含图片、封面标题、副标题、标签

#### Scenario: 未设封面标题时列表回落文章标题
- **GIVEN** 某栏目下有一篇上线文章，其封面标题为空
- **WHEN** app 端查该栏目文章列表
- **THEN** 该文章的封面标题字段返回其文章标题

#### Scenario: 详情返回引言与标签
- **GIVEN** 一篇可见文章，设置了引言与两个标签
- **WHEN** app 端查该文章详情
- **THEN** 返回 200，详情含该引言与两个标签；未设引言时该字段为 null、未设标签时为空数组

#### Scenario: 下线文章不可见
- **GIVEN** 某栏目下有一篇下线文章
- **WHEN** app 端查该栏目文章列表及该文章详情
- **THEN** 列表不含该文章；详情返回 404

#### Scenario: 失去所有栏目的文章不可见
- **GIVEN** 一篇上线文章仅关联一个栏目，随后该栏目被删除
- **WHEN** app 端查该文章详情
- **THEN** 返回 404

#### Scenario: 文章详情返回富文本
- **GIVEN** 一篇可见文章，内容为含图片标签的 HTML
- **WHEN** app 端查该文章详情
- **THEN** 返回 200，contentHtml 中图片 src 为签名 URL

### Requirement: web 端文章管理页面
web 端 SHALL 提供「文章栏目」与「文章管理」两个后台页面：栏目页为 DataTable 列表（icon/名称/权重/操作）+ 弹窗表单；文章页为 DataTable 列表（图片/封面标题/文章标题/关联栏目/状态/操作）+ 独立表单页（含封面标题、文章标题、副标题、引言、标签输入、富文本编辑器、栏目多选）+ 上下线开关 + 删除确认弹窗。标签输入 SHALL 复用形象大使页既有的标签编辑模式：每条标签一个文本输入框加「删除」按钮，下方「添加标签」按钮追加空行；保存时空白标签自动剔除，条数不设上限。

#### Scenario: 栏目管理增删改
- **GIVEN** 已登录后台
- **WHEN** 在文章栏目页新增一个栏目并再删除它
- **THEN** 列表即时刷新，删除前有确认弹窗

#### Scenario: 文章列表与上下线
- **GIVEN** 已登录后台且存在文章
- **WHEN** 进入文章管理页并切换某文章状态开关
- **THEN** 列表展示图片、封面标题、文章标题、关联栏目，切换后状态即时更新并有成功提示

#### Scenario: 文章表单富文本编辑
- **GIVEN** 文章编辑表单已打开
- **WHEN** 在文章内容富文本编辑器中输入图文内容、多选栏目并保存
- **THEN** 保存成功，重新打开表单富文本与栏目多选回显

#### Scenario: 表单填写封面标题、引言与标签
- **GIVEN** 文章新建表单已打开
- **WHEN** 填写封面标题、文章标题、引言，并通过「添加标签」录入两个标签后保存
- **THEN** 保存成功，重新打开表单四项均回显；点击某条标签的「删除」按钮可将其移除

#### Scenario: 存量文章封面标题为空时表单可正常打开
- **GIVEN** 一篇创建于本次变更之前、无封面标题与引言的文章
- **WHEN** 打开其编辑表单
- **THEN** 封面标题与引言输入框为空、标签区为空，其余字段正常回显，不报错
