# article Specification

## Purpose
文章栏目与文章内容管理：admin 端维护栏目与富文本文章，app 端只读展示（需求文档 §6）。
## Requirements
### Requirement: 文章栏目管理
admin 端 SHALL 提供文章栏目 CRUD：栏目名称（必填）、icon 图片 1 张（必填）、栏目权重（排序号，整数）。删除为物理删除；删除栏目不影响已关联文章的数据，但文章与该栏目的关联随之失效。

#### Scenario: 创建栏目
- **GIVEN** 已登录 admin
- **WHEN** 提交名称、icon 图片、权重完整的栏目
- **THEN** 返回 200，详情含名称、icon 签名 URL、权重

#### Scenario: 缺少必填项被拒绝
- **GIVEN** 已登录 admin
- **WHEN** 提交缺名称或缺 icon 的栏目
- **THEN** 返回 400 及中文业务错误

#### Scenario: 删除栏目不影响文章数据
- **GIVEN** 某栏目下关联有文章
- **WHEN** 删除该栏目
- **THEN** 返回 200；文章记录仍存在，其关联栏目列表不再含该栏目

### Requirement: 文章管理
admin 端 SHALL 提供文章 CRUD：文章图片 1 张（必填）、文章标题（必填）、文章副标题、文章内容（富文本存 HTML，img src 存 objectKey、读时替换签名 URL）、文章权重（排序号）、关联栏目多选（一篇文章可属多个栏目，栏目必须存在）、上线/下线状态。删除为物理删除。

#### Scenario: 创建文章
- **GIVEN** 存在两个栏目
- **WHEN** 提交关联这两个栏目、含富文本内容的完整文章
- **THEN** 返回 200，详情字段齐全，关联栏目为两个，富文本 HTML 保存成功

#### Scenario: 缺少必填项被拒绝
- **GIVEN** 已登录 admin
- **WHEN** 提交缺标题或缺图片或关联了不存在栏目的文章
- **THEN** 返回 400 及中文业务错误

#### Scenario: 文章上下线切换
- **GIVEN** 一个上线文章
- **WHEN** 将其下线
- **THEN** 返回 200，详情 online=false

### Requirement: App 端文章查询
app 端 SHALL 提供只读查询：栏目列表（按权重升序，含名称与 icon）、按栏目查文章列表（按文章权重升序，含图片、标题、副标题）、文章详情（含富文本 HTML，img src 为签名 URL）。文章仅当上线**且**至少关联一个仍存在的栏目时可见；不可见文章详情返回 404。

#### Scenario: 查询栏目与文章列表
- **GIVEN** 存在两个栏目（权重 2、1），权重小的栏目下有两篇上线文章（权重 3、1）
- **WHEN** app 端查栏目列表、再按该栏目查文章列表
- **THEN** 栏目按权重升序返回；文章按权重升序返回，含图片、标题、副标题

#### Scenario: 下线文章不可见
- **GIVEN** 某栏目下有一篇下线文章
- **WHEN** app 端查该栏目文章列表及该文章详情
- **THEN** 列表不含该文章；详情返回 404

#### Scenario: 失去所有栏目的文章不可见
- **GIVEN** 一篇上线文章仅关联一个栏目，随后该栏目被删除
- **WHEN** app 端查该文章详情
- **THEN** 返回 404

#### Scenario: 文章详情返回富文本
- **GIVEN** 一篇可见文章，内容为含图片标签的 HTML
- **WHEN** app 端查该文章详情
- **THEN** 返回 200，contentHtml 中图片 src 为签名 URL

### Requirement: web 端文章管理页面
web 端 SHALL 提供「文章栏目」与「文章管理」两个后台页面：栏目页为 DataTable 列表（icon/名称/权重/操作）+ 弹窗表单；文章页为 DataTable 列表（图片/标题/关联栏目/状态/操作）+ 独立表单页（含富文本编辑器、栏目多选）+ 上下线开关 + 删除确认弹窗。

#### Scenario: 栏目管理增删改
- **GIVEN** 已登录后台
- **WHEN** 在文章栏目页新增一个栏目并再删除它
- **THEN** 列表即时刷新，删除前有确认弹窗

#### Scenario: 文章列表与上下线
- **GIVEN** 已登录后台且存在文章
- **WHEN** 进入文章管理页并切换某文章状态开关
- **THEN** 列表展示图片、标题、关联栏目，切换后状态即时更新并有成功提示

#### Scenario: 文章表单富文本编辑
- **GIVEN** 文章编辑表单已打开
- **WHEN** 在文章内容富文本编辑器中输入图文内容、多选栏目并保存
- **THEN** 保存成功，重新打开表单富文本与栏目多选回显
