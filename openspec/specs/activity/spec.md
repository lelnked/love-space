## Requirements
### Requirement: 活动管理
admin 端 SHALL 提供活动 CRUD：活动图片最少 1 张、活动标题（必填）、活动标签（多个文本）、适合周期多选（经期/卵泡期/排卵期/黄体期）、活动级别单选（L1/L2/L3）、活动副标题（可空文本）、活动简介、编辑说、集合地、解散地、交通、签证、景观（均文本）、路线子条目列表（每条为标题+内容，按添加顺序保存与展示）、活动详情说明（富文本，存 HTML）、上线/下线状态。活动 SHALL NOT 关联地图（城市）——请求体中的 `cityId` 不再被接受，响应中不再返回 `cityId`，列表查询不再支持按城市过滤。删除为物理删除。

#### Scenario: 创建活动
- **GIVEN** 已登录 admin
- **WHEN** 提交完整活动（2 张图、2 条标签、周期多选、级别 L2、景观文本、2 条路线子条目、富文本详情、上线），请求体不含 cityId
- **THEN** 返回 200，详情字段齐全（含 landscape 景观）且不含 cityId，路线子条目按提交顺序返回，详情 HTML 原样保存

#### Scenario: 缺少必填项被拒绝
- **GIVEN** 已登录 admin
- **WHEN** 提交缺标题或图片为空的活动
- **THEN** 返回 400 及中文业务错误

#### Scenario: 请求体携带 cityId 不影响创建
- **GIVEN** 已登录 admin
- **WHEN** 提交合法活动但请求体额外携带 `cityId`
- **THEN** 返回 200，该字段被忽略，详情响应中不含 cityId

#### Scenario: 活动列表不按城市过滤
- **GIVEN** 存在若干活动
- **WHEN** 请求 `GET /api/admin/activities/page` 并携带 `cityId` 查询参数
- **THEN** 返回 200，结果为全部活动（不因该参数收窄），每条不含 cityId 字段

#### Scenario: 活动上下线切换
- **GIVEN** 一个上线活动
- **WHEN** 将其下线
- **THEN** 返回 200，详情 online=false

#### Scenario: 副标题可写可改可空
- **GIVEN** 已登录 admin
- **WHEN** 创建活动时填写副标题「一日徒步」，随后更新为「两日徒步」，再提交不带该字段的更新
- **THEN** 三次操作均返回 200，详情 `subtitle` 依次为「一日徒步」「两日徒步」与 null

#### Scenario: 景观字段可写可改可空
- **GIVEN** 已登录 admin
- **WHEN** 创建活动时填写景观「海岸线景观」，随后更新为「火山地貌」
- **THEN** 两次操作均返回 200，详情 `landscape` 分别为「海岸线景观」与「火山地貌」；不传该字段时为 null

### Requirement: App 端活动查询
app 端 SHALL 提供只读查询：查全部上线活动列表（含图片、标题、副标题、标签、级别、周期，按创建时间倒序）与活动详情（含全部字段——含景观 landscape——与富文本 HTML）。可见性 SHALL 仅由活动自身 `online` 决定，不再受任何城市上架状态影响；列表接口 SHALL NOT 接受 `cityId` 参数；详情响应 SHALL NOT 返回 `cityId`。下线活动不出现在列表中，其详情返回 404。

#### Scenario: 查询上架城市的活动
- **GIVEN** 存在多个上线活动，其中部分活动此前归属的城市已下架
- **WHEN** app 端请求 `GET /api/app/activities`（不带任何参数）
- **THEN** 返回 200，含全部上线活动（不因任何城市上架状态被筛掉），按创建时间倒序，每条含标题、副标题、图片、级别、周期字段

#### Scenario: 下线活动不可见
- **GIVEN** 一个下线活动
- **WHEN** app 端查活动列表及该活动详情
- **THEN** 列表不含该活动；详情返回 404

#### Scenario: 城市上架状态不影响活动详情可见性
- **GIVEN** 一个上线活动，且系统中存在已下架城市
- **WHEN** app 端查该活动详情
- **THEN** 返回 200——结果与任何城市的上架状态无关

#### Scenario: 活动详情返回富文本
- **GIVEN** 一个上线活动，详情说明为含图片标签的 HTML
- **WHEN** app 端查该活动详情
- **THEN** 返回 200，detailHtml 与后台保存内容一致，响应不含 cityId

#### Scenario: 活动副标题下发且未填时为 null
- **GIVEN** 两个上线活动，一个填写了副标题，一个未填写
- **WHEN** app 端查活动列表与这两个活动的详情
- **THEN** 返回 200，填写者的 `subtitle` 为其副标题文本，未填写者的 `subtitle` 为 null（不回落为标题）

### Requirement: web 端活动管理页面
web 端 SHALL 提供「活动管理」后台页面：DataTable 列表（图片/标题/级别/状态/操作）+ 表单（含副标题输入框、标签、周期多选、级别单选、景观文本框、路线子条目增删、富文本编辑器仅用于活动详情说明）+ 上下线开关 + 删除确认弹窗。列表 SHALL NOT 提供「所属地图（城市）」筛选项与列，表单 SHALL NOT 提供「所属地图（城市）」下拉项。

#### Scenario: 活动列表与上下线
- **GIVEN** 已登录后台且存在活动
- **WHEN** 进入活动管理页并切换某活动状态开关
- **THEN** 列表展示图片、标题、级别，无「所属城市」列，筛选区无地图（城市）下拉，切换后状态即时更新并有成功提示

#### Scenario: 活动表单无地图选项即可保存
- **GIVEN** 已登录后台
- **WHEN** 打开活动新增表单，填写标题与至少 1 张图片后保存
- **THEN** 表单中不存在「所属地图（城市）」下拉项，保存成功并返回列表

#### Scenario: 活动表单富文本编辑
- **GIVEN** 活动编辑表单已打开
- **WHEN** 在活动详情说明的富文本编辑器中输入图文内容并保存
- **THEN** 保存成功，重新打开表单富文本内容回显

#### Scenario: 活动表单填写景观并回显
- **GIVEN** 活动表单已打开
- **WHEN** 在「景观」输入框填写文本并保存，随后重新打开该活动的编辑表单
- **THEN** 保存成功，「景观」输入框回显此前填写的文本

#### Scenario: 活动表单填写副标题并回显
- **GIVEN** 活动表单已打开
- **WHEN** 在「副标题」输入框填写文本并保存，随后重新打开该活动的编辑表单
- **THEN** 保存成功，「副标题」输入框回显此前填写的文本
