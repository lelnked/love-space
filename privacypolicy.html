欢迎使用「同类象App」。「同类象」由【成都合并科技有限责任公司】提供。我们重视你的个人信息和隐私保护，并希望通过本《隐私政策》向你说明：我们如何处理你的信息、你享有哪些权利，以及你如何联系我们。

请你在使用同类象前仔细阅读并理解本政策。你使用同类象，即表示你已理解并同意本政策的内容。如你不同意本政策的任何内容，请立即停止使用同类象。

一、我们如何收集和使用信息

本地记录信息

为了向你提供身体节律记录、状态洞察、周期提醒和生活建议功能，你可以在同类象中主动记录或选择以下信息：

  • 经期开始日期、结束日期、周期长度等周期相关信息；
  • 身体感受、症状、疼痛等身体状态信息；
  • 情绪状态、心理感受等记录信息；
  • 饮食、运动、护肤、睡眠或其他你主动填写、选择或生成的生活记录。

当前版本中，上述信息默认存储在你的设备本地，用于在设备内生成周期预测、状态观察、提醒和个性化生活建议。我们不会将这些用户主动记录的数据上传至我们的服务器进行存储。

设备权限信息

为了实现部分功能，同类象可能会请求使用以下系统权限。是否授权由你自行决定，你也可以随时在设备系统设置中关闭相关权限。

通知权限

用于向你发送周期提醒、状态提醒、记录提醒或生活建议提醒。关闭通知权限后，你仍可使用 App，但将无法收到系统通知提醒。

健康数据权限，如 Apple Health / HealthKit

如同类象后续接入 Apple Health / HealthKit，我们会在具体功能场景中向你说明需要读取的数据类型和使用目的，并在取得你的明确授权后读取相关数据。你可以随时在 iOS 系统设置或健康 App 中管理或撤回授权。

除非你主动授权，否则同类象不会读取你的 Apple Health / HealthKit 数据。我们不会将 HealthKit 数据用于广告、营销或出售，也不会在未取得你授权的情况下与第三方共享 HealthKit 数据。

设备信息、日志信息与基础运行信息

为了保障 App 的基础运行、安全维护、故障排查和性能优化，同类象可能会处理必要的设备信息或日志信息，例如：

  • 设备型号、操作系统版本、App 版本；
  • 崩溃日志、错误日志、性能日志；
  • 基础使用状态，例如功能是否正常打开、页面是否发生异常等。

我们会尽量避免通过上述信息识别特定个人，并仅在实现基础运行、安全维护、问题排查和产品优化所必要的范围内使用。

二、我们如何存储信息

  1. 当前版本中，你主动记录的经期、身体状态、情绪及相关生活数据默认存储在你的设备本地。
  2. 我们不会将上述用户主动记录的数据上传至我们的服务器进行存储。
  3. 如你卸载 App、更换设备、清除 App 数据、系统故障或设备损坏，可能导致本地记录丢失。请你自行注意设备安全和数据管理。
  4. 如我们为了崩溃分析、性能监测或基础统计接入第三方服务，相关数据的存储地点和期限将以对应第三方服务规则及本政策说明为准。

三、我们如何使用信息

我们可能基于以下目的处理必要信息：

  1. 提供身体节律记录、周期预测、状态洞察和生活建议功能；
  2. 在你的设备本地生成个性化提醒、趋势观察和内容推荐；
  3. 保障 App 的安全、稳定运行；
  4. 排查崩溃、错误、卡顿或其他技术问题；
  5. 优化产品体验、界面设计和功能流程；
  6. 履行法律法规要求或监管要求。

我们不会将你的本地身体记录、经期记录或情绪记录出售给任何第三方，也不会将其用于广告追踪。

四、我们如何共享、转让或公开披露信息

共享

当前版本中，我们不会将你主动记录的经期、身体状态、情绪及相关生活数据上传至我们的服务器，也不会主动向第三方共享这些本地记录数据。

但在以下情况下，可能涉及必要的信息处理或共享：

  1. 你主动授权或明确同意；
  2. 为实现崩溃排查、性能监测、基础统计等功能，第三方 SDK 按其规则处理必要的设备信息或日志信息；
  3. 根据法律法规、司法机关、行政机关或监管机构的合法要求；
  4. 为保护你、其他用户、我们或社会公共利益所合理必要。

如后续新增第三方 SDK 或第三方服务，我们会根据实际情况更新本政策。

转让

我们不会将你的个人信息转让给任何公司、组织或个人，但以下情况除外：

  1. 取得你的明确同意；
  2. 因合并、分立、收购、资产转让、破产清算或类似交易需要转移的，我们会要求新的持有方继续受本政策约束，并依法向你告知相关情况。

公开披露

我们不会公开披露你的个人信息，除非：

  1. 取得你的明确同意；
  2. 法律法规、司法机关或行政机关要求披露。

五、敏感个人信息说明

经期、身体状态、症状、情绪状态、健康相关记录等信息可能属于敏感个人信息。该类信息一旦泄露或被非法使用，可能对你的人格尊严、人身安全、财产安全或个人生活造成影响。

在当前版本中，这些信息默认仅存储在你的设备本地，并用于本地生成周期预测、状态洞察、提醒和生活建议。我们建议你：

  1. 妥善保管手机、平板等设备；
  2. 为设备设置密码、Face ID 或 Touch ID；
  3. 避免将设备长期交由他人使用；
  4. 在转让、出售或维修设备前，自行备份并清除相关数据；
  5. 谨慎截图、分享或导出包含个人身体状态的信息。

如后续功能需要将敏感个人信息上传、同步、备份或提供给第三方处理，我们会在功能上线前更新本政策，并在必要时取得你的单独同意。

六、我们如何保护信息安全

我们会采取合理可行的安全措施保护你的信息安全，包括但不限于：

  1. 尽量减少不必要的信息收集；
  2. 对敏感功能采取本地处理优先的设计；
  3. 限制信息处理范围，仅在实现功能所必要的范围内使用；
  4. 根据实际技术条件采取访问控制、加密、权限管理等安全措施；
  5. 审慎选择第三方 SDK 或服务，并关注其隐私与安全合规情况。

但请你理解，互联网环境、移动设备系统和软件服务不存在绝对安全。由于你自身设备管理不当、系统漏洞、恶意软件、第三方原因或不可抗力导致的信息泄露、丢失或损害，我们将在法律规定范围内承担相应责任。

七、你的权利

你对自己的个人信息依法享有访问、更正、复制、删除、撤回授权、限制处理、注销相关服务等权利。

在当前版本中，同类象不设账号系统，且用户主动记录的数据默认保存在你的设备本地。因此，你可以通过以下方式管理相关信息：

  1. 在 App 内删除或修改你主动记录的内容；
  2. 在设备系统设置中关闭通知、HealthKit 或其他系统权限；
  3. 卸载 App 或清除 App 数据，以删除设备本地保存的相关数据；
  4. 如你对信息处理有疑问，可以通过本政策列明的联系方式与我们联系。

八、未成年人保护

同类象主要面向具备相应民事行为能力的用户。若你为未成年人，应在父母或其他监护人的同意和指导下使用本服务。

如你未满十四周岁，请在监护人同意后使用同类象，并避免在未经监护人同意的情况下填写或保存敏感个人信息。

如监护人发现未成年人未经同意使用同类象或填写相关信息，可通过本政策列明的联系方式与我们联系，我们将依法处理。
